# E3.3.7 Phase 4 / P4-E4B — ENP Production Receive-Path Integration

**Status:** PASS / FROZEN

P4-E4B integrates the validated data-plane behavior into the reusable ENP production receive path. Transport RX is classified so DATA/ACK traffic enters the ENP data plane, while other packet types continue through the normal dispatcher path.

Validated with ESP-IDF 6.0.2:

- production receive path initialization and binding;
- local DATA delivery through the data plane and local dispatcher boundary;
- duplicate local DATA suppression in the data-plane domain;
- local ACK delivery through the data plane;
- non-DATA/ACK traffic remaining on the normal dispatcher path;
- normal dispatcher duplicate suppression for Discovery;
- non-local DATA reaching the routing data path;
- TTL decrement from 8 to 7;
- preservation of DATA transaction identity;
- selection of the configured next-hop transport address;
- clean receive-path, dispatcher and context deinitialization.

P4-E4B is frozen.
