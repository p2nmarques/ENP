# E3.3.7 Phase 4 / P4-E4A — Dispatcher Local Dispatch

**Status:** PASS / FROZEN

P4-E4A validates the local-dispatch boundary used by the ENP data plane. `enp_dispatcher_dispatch_local()` delivers a local packet directly to the registered service without applying the generic dispatcher duplicate cache. Normal dispatcher dispatch retains generic duplicate suppression based on source logical address plus sequence.

Validated with ESP-IDF 6.0.2:

- dispatcher initialization;
- application service registration;
- local DATA delivery;
- preservation of packet/source identity;
- local dispatch bypass of the generic duplicate cache;
- normal dispatcher first delivery;
- normal dispatcher suppression of an identical duplicate;
- clean dispatcher deinitialization.

P4-E4A is frozen.
