## 5. Scope boundary

This validation establishes **P4-E5C hardware validation**.

It does not validate:

- successful real ESP-NOW delivery;
- RERR generation or processing;
- RREQ/RREP;
- route discovery;
- route repair;
- alternate-path selection;
- reliability retransmission/recovery.

Those remain separate future validation boundaries.
